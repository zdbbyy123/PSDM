# PSDM Inference Package

This directory contains only the files required to predict user-provided VCF variants:

```text
PSDM_inference_clean/
├── predict.py
├── PSDM.model.zip
├── requirements.txt
└── README.md
```

`PSDM.model.zip` contains the complete five-fold ensemble, 350 LightGBM learners, and all preprocessing parameters. The outer `fold_1`–`fold_5` directories are not required for inference.

## Usage

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Export the required annotation schema:

```bash
python predict.py --describe > annotation_schema.json
```

Predict a new VCF:

```bash
python predict.py \
  --vcf new_variants.vcf \
  --annotations new_annotations.tsv.gz \
  --output new_predictions.tsv
```

The user must provide:

1. A GRCh38/hg38 VCF containing biallelic SNVs;
2. An external annotation file with exactly the 260 features required by the model;
3. Matching `chrom`, `pos`, `ref`, and `alt` values between the annotation file and the VCF.

The output contains `variant_id`, `chrom`, `pos`, `ref`, `alt`, `psdm_score`, and `predicted_label`. A variant is labeled positive when `psdm_score >= 0.5`.

Important: the model cannot generate sequence, conservation, splicing, or other required features from chromosome coordinates and REF/ALT alone. These annotations must be generated by an external pipeline before prediction.
